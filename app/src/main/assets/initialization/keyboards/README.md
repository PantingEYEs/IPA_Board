# 初始化键盘页配置

在此目录放入首次初始化时提供的键盘页 JSON 配置文件，可放置多个文件，每个文件对应一个键盘页。

请使用软件导出的键盘页 JSON 格式，并为各文件使用不同的文件名。

仅在首次初始化时自动加载本目录中的 JSON 文件；保留已有用户配置，删除后不自动补回。

初始化逐个调用与手动导入相同的导入函数。文件名和数量不限（包括空目录），只处理 .json 文件（扩展名不区分大小写），按文件名排序导入。
支持普通布局 JSON 与带 layout、appearance 的导出配置；外观和当前页随导入更新，最终使用最后导入的页面与外观。

`注音.json` 提供完整的 37 个注音符号及五个声调符号，符号键使用 `auto` 输入行为生成汉字候选，标点维持原有配置。底部宽键输入一声符号 `ˉ`，其左右滑动仍用于切换键盘页。当前输入逻辑也支持已有用户页面的注音键，无须重新初始化或覆盖配置；旧页若只有空格键，可将任一按键或长按绑定为 `ˉ` 来明确输入一声；空格仍用于选择候选。密码、数字等直接输入框会按字符直接输入。
