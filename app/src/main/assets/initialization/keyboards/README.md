# 初始化键盘页组配置

每个直接子目录是一份独立页组预设，与 Keyboard Management → Group Settings 的文件夹导入／导出使用相同格式。目录内放该组的键盘页 JSON，以及可选的 `group_config.json`；不递归读取更深层目录。

当前预设由维护者提供的最新键盘配置生成：`Default`（4 页）、`IPA`（1 页）、`Uncommon`（10 页）。页面内容保留原配置，元数据保留组内页面顺序、选中页及完整外观。页组文件夹名决定导入后的名称。

- `group_config.json` 使用 `format: "ipa-board-page-group"`、`schemaVersion: 1`，包括 `appearance`、`pages` 和 `activePage`。具体格式见 [页组文件夹导入／导出](../../../../../../docs/page-group-transfer.md)。
- 元数据缺省时使用默认外观，页面按来源实际枚举顺序排列，首个页面为默认选中页；不从单页文件继承旧的外观字段。
- 新安装在首次初始化时，通过与手动导入相同的校验和事务逻辑加载所有页组。已有页面、已有页组或旧初始化标记均阻止重新填充。升级不覆盖用户配置，用户删除的预设不自动补回。
- 初始化失败不保留部分导入结果，修复资源或存储问题后可重试。手动导入同名页组和页面会创建自动改名的独立副本。

单页导入仍可使用普通布局 JSON 或带 `layout` 的历史导出格式。维护预设时可以直接调整目录内的页面 JSON；改名、增加或删除页面后，也需同步修改该目录的 `group_config.json`。
