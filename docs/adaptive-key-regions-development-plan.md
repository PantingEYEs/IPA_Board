# 自适应按键区域（Adaptive Key Regions）开发计划

状态：需求已形成，尚未实现、尚未排期。**安排在统一个人词典功能之后，不列为 0.0.4 必须交付的内容。** 本文依据维护者已确认的行为制定；实现建议与待定事项分别列明，不表示已经选定依赖、完成性能验证或证明输入准确率提升。

代码核对基线：`6c4f374`。文中“当前”均指这一基线。

## 1. 功能定位与已确认规则

本功能保留键盘页原有行列、按键内容和功能绑定，增加由生成元与动态权重决定的触摸命中区域。区域可以跨越原有矩形边界，也可以具有曲线边界。它改变触点归属，不自动重排原有行列或改写输入内容。

| 项目 | 已确认的行为 |
| --- | --- |
| Lv.0 | 保留当前布局与操作方式，可以随时切回 |
| 生成元 | 点、线或折线图形与按键关联；程序可依据原键盘生成，用户可以调整 |
| 不绑定生成元的键 | 可从 Lv.1 键盘中消失，但保留 Lv.0 原始按键和配置 |
| 动态权重 | 主要依据下一键预测调整；扩张结果同时受相邻生成元约束，不保证权重与面积成正比 |
| 单键频率 | 可以同时收集，作为置信度较低的退避数据，不能代替有上下文的下一键预测 |
| 最小区域 | 不允许动态权重把其他仍有生成元的键完全挤掉；最小大小及度量方式待实测 |
| Grid | 沿用页组 Show Keyboard Grid；绘制与命中共用同一份几何状态 |
| 手势稳定性 | 一次手势使用稳定的权重与几何快照，不能因异步预测中途改变按键归属 |
| 个人词典 | 对所有键盘页有效，不按页复制成互不相通的词典 |
| 经验和输入习惯 | 归属具体键盘页；用户可以为页面开启采集 |
| 学习确认 | 关联最终确认词条与输入序列，处理纠正和撤销，不能把原始误触直接当作正确标签 |
| 经验与升级 | 一次有效的成功入典记录称为 1 经验值；达到待定门槛可由 Lv.0 升为 Lv.1，Lv.1 才能启用预测 |
| 修改配置升级 | 不阻止用户通过修改配置直接使用 Lv.1；经验门槛不是防篡改限制 |
| 分享 | Lv.1 键盘可以分享，并在接收者后续使用中继续适应其习惯 |
| 重置 Lv.1 | **仅清除生成元布局与生成元绑定按键的数据**；不清经验、学习参数、个人词典、Lv.0 行列或原有按键功能绑定 |

这里的“生成元绑定按键”与“按键绑定输入功能”是两层关系。重置前者不能删除后者。本文使用“自适应按键区域”作为功能名，避免与原有键盘行列编辑混淆。

## 2. 最终使用效果

1. 用户先使用统一个人词典；在某个键盘页开启采集后，Lv.0 的有效输入也能积累该页经验。
2. 最终词条确认并成功入典后，记录对应页面、输入序列及确认结果。通过去重与撤销机制维护有效学习贡献。
3. 达到门槛时，用户可以升级并采用程序生成的生成元，也可以调整生成元及其按键关联。升级交互和编辑器样式尚未指定。
4. Lv.1 中，字母键可以采用点，空格等宽键可以采用线段；折线用于表达更自由的可达区域。这只是生成建议，不限制用户必须采用这些形状。
5. 例如上下文预测更可能输入 `u` 时，程序尝试扩大对应键的命中范围；其他键仍满足最小区域约束。遇到缺少证据的上下文，降低调整幅度，避免低置信猜测持续挤压其他键。
6. 开启 Show Keyboard Grid 后，Lv.1 显示当前实际命中区域，Lv.0 保持现有矩形网格；关闭 Grid 只隐藏边线，不关闭预测或改变命中算法。标签位置保留原有视觉锚点，主动取消生成元关联的键按 Lv.1 隐藏规则处理。
7. 手指按下后，该次手势的命中几何固定。预测或布局更新只在合适的后续时机生效，不能打断正在进行的长按、Popup、滑动或持续功能。
8. 用户可以切回 Lv.0。重置 Lv.1 后，生成元布局与关联被清空，经验和学习仍在；此时重新生成、暂时回退显示或等待配置的具体交互，见第 11 节。
9. 分享来的 Lv.1 可以直接使用，不要求接收者重新满足升级门槛。接收者继续积累本页经验，逐步形成自己的预测参数；初始分享参数不保证立即适合新用户。

最终目标是提高实际点按准确率。它不承诺自动学习后必然优于 Lv.0，也不自动扩展为滑行输入、整句纠错、生成式补全或自动移动键面标签。

## 4. 前置工作与依赖顺序

### 4.1 必须先完成的部分

| 前置工作 | 最少需要解决的问题 | 原因 |
| --- | --- | --- |
| 统一个人词典 | 所有页面可访问词条；区分词条身份与一次确认记录；能报告新增、更新、纠正、撤销 | “词典中有这个词”与“用户又确认了一次输入”不是同一事件 |
| 输入来源记录 | 页面 ID、按键 ID、动作类型、序列顺序、实际产生的编码/文本 | 最终字符串无法唯一反推出用户按了哪些键 |
| 有效入典及学习账本 | 确认事件有唯一身份，学习贡献可撤销或重建，重启和重试不会重复计数 | 支撑 1 经验事件、纠错和撤销 |
| 稳定配置身份 | 页面、原始按键、生成元、学习模型分别标识并记录版本 | 重置生成元仍要保留模型；改名不能变成新用户，导入副本不能误写旧模型 |
| 统一几何与事件路由 | 相同区域定义用于绘制和命中，能够保留完整手势状态 | 当前矩形 View 的分发和移出判定不能直接覆盖不规则区域 |
| 最小区域校验与失败回退 | 有效基线、约束判定、有限求解预算和安全的旧状态 | 预测失效时仍应有可用键盘，不能卡住输入 |

`InputConnection.commitText()` 返回成功，只表示编辑器接受调用，不表示词条已经入典或用户最终确认正确。外部光标变化、Gemini/Notion 等编辑器重建输入区，也不能直接计为有效入典。现有 [#17](https://github.com/PantingEYEs/IPA_Board/issues/17)、[#37](https://github.com/PantingEYEs/IPA_Board/issues/37) 是需要保护的相关场景，不预先假定它们与本功能有共同根因。

### 4.2 分词器何时需要

**按键序列 n-gram 基线不依赖自然语言分词器，也不应强制依赖 E5。** 如果用户明确确认一个词条，可以直接把该次确认作为词条边界，再对关联的按键序列学习。

只有从连续句子自动发现词条、建立词级上下文或自动判定多词边界时，才需要相应的分词策略。需要分别处理：

- 空格与标点分词的语言，以及中文、日文等无空格文本。
- IPA 组合符、附加符号、Emoji、多码点字素和混合脚本。
- 拼音/注音等原始编码与最终汉字的关系。
- 多字符文本键、快捷文本、候选补全与实际逐键输入的区别。

SentencePiece 的子词 ID、自然语言的“词”和物理按键 ID 是不同单位。不能用现有 E5 tokenizer 直接替代上述边界设计。分词实现与覆盖语言应在个人词典阶段明确；第一阶段可以仅接受显式确认词条，避免把“万能分词器”设为启动条件。

## 5. 建议的数据与学习实现

### 5.1 分开保存的状态

| 数据 | 归属与作用 | 重置 Lv.1 是否清除 |
| --- | --- | --- |
| 个人词典 | 应用级，服务所有页面 | 否 |
| Lv.0 行列与按键功能 | 页面及原始按键 | 否 |
| 经验、等级和采集状态 | 页面 | 否 |
| 下一键模型、低置信单键频率 | 页面；以稳定按键身份索引 | 否 |
| 确认/纠正/撤销记录 | 可关联页面与词条的学习账本；保存策略待定 | 否；几何重置不应顺带删除学习记录 |
| 生成元形状、坐标及按键关联 | Lv.1 几何配置 | **是** |
| 当前几何快照 | 根据配置、模型和可用尺寸计算的临时状态 | 失效并重新选择有效状态；它不是需要保留的个人模型 |

建议给模型记录所适用的按键集合/配置版本。重置几何后，可以重新关联原有按键并继续使用其学习数据；若键义已被编辑成不同内容，需识别模型不兼容，不能因 ID 相同就无条件沿用。

### 5.2 学习闭环

```text
按键事件与来源 → 暂存输入序列 → 最终词条确认并入典
                                      ↓
                           唯一确认记录与有效经验
                                      ↓
                          页面模型的可追踪学习增量
                                      ↓
                    纠正/撤销 → 撤销、重标或重建对应增量
```

建议先采用可增减计数的模型：一次确认记录对应一组更新，撤销时能撤回对应贡献。若以后改为难以精确逆转的训练方法，必须提供重放重建或等价补偿机制，不能只删除界面中的记录而保留误学结果。

学习样本至少需要区分实际按键序列、实际编码、最终词条和确认来源。例如输入 `nihao` 后选择“你好”，不能直接把汉字当作物理按键；引擎纠正了错误编码时，也不能把纠正前序列全部视为正确输入。无法可靠对齐的记录，可以参与词典或低置信统计；是否更新几何预测应另行判断，不能伪造“正确按键”。

粘贴、Emoji/颜文字面板、多字符快捷输入和编辑器外部写入不能自动拆成假想触点。它们能否提供词条、上下文或经验，需要与真实逐键训练分开定义。

1 经验值仍以维护者确定的有效入典记录为单位，不改成按键次数、候选刷新次数或句子字符数。重复词条确认、多页共同完成词条、撤销后是否扣经验及是否影响已获得等级，仍需补充规则。

### 5.3 下一键预测

建议第一版使用页面级按键序列 n-gram，并做平滑和上下文退避：优先使用有足够证据的上下文，证据不足时退回较短上下文，再使用低置信单键频率，最终回到基础权重。n 的取值、数据量阈值、遗忘/衰减和置信度估计都需实测。

模型输出“下一键概率/置信度”，几何层再把它转换为权重或偏置。概率、经验值和几何权重不是同一个量。样本越多也不自动等于模型越好，不能把 Lv.1 门槛当作质量证明。

初期不要求神经网络、大模型或在线下载预测服务。先证明简单模型能降低误触且延迟可接受，再决定是否扩展模型。已有 E5 语义排序保持独立。

## 6. 数学依据与候选几何方案

### 6.1 有效键盘域与生成元

令有效键盘区域为 Ω，参与命中的生成元为 G₁…Gₙ。点到折线的距离取到组成线段的最近距离；一条折线拆成多段仅是计算细节，最终仍归属同一个键。n=0、Ω 为空或坐标/权重出现非有限值时，不存在可发布的有效命中分区；应选择安全可用状态，并保留等级、经验与模型。

坐标需可随屏幕尺寸重建，但距离度量必须一致。若分别把 x、y 拉伸到单位区间后直接计算欧氏距离，会改变物理长宽关系；应保留尺度信息或明确使用的变换度量。Split 中央空白、候选栏、多功能栏和 Popup 是否属于 Ω，须按各自交互明确，不能因为 Voronoi 会铺满平面就让它吞掉非键区。

[CGAL 的线段 Voronoi 定义](https://doc.cgal.org/latest/Segment_Delaunay_graph_2/index.html)可作为点/线段最近距离及退化情况的依据。折线、相交生成元可能产生更复杂的区域，不能默认每个键都对应一个凸多边形。

### 6.2 候选评分与概率解释

一个可供原型验证的评分是：

```text
score_i(p) = d(p, G_i)² − b_i
key(p)     = argmin_i score_i(p)
b_i        = λ × (w_i − 0.5)      # 仅为候选映射，不是已敲定公式
```

默认权重 `0.5` 是候选基线值，最终范围和扩张强度尚未确定。在其他偏置不变时，提高 bᵢ 会使该键的区域不缩小，但不保证面积线性增加。加入最小区域约束后，预测提出的权重可能被减弱或拒绝。

对点生成元，该平方距离减偏置形式与 power diagram 对应。加法加权 Voronoi 的 `d − w` 是另一种距离，不能把两者的实现混用；[CGAL Apollonius 文档](https://doc.cgal.org/latest/Apollonius_graph_2/index.html)也明确说明带权区域可以为空。

从贝叶斯判定看：选择使“触点似然 × 下一键先验概率”最大的键。在共同方差的点高斯模型下，负对数可化为“平方距离减对数先验”一类代价。它说明语言预测与触点几何如何组合；对任意长度的线段/折线直接套用只是候选能量模型，若声称是严格概率模型，还要处理似然归一化。

### 6.3 最小区域是独立约束

要求每个仍参与的键具有最小区域 Aᵢ ≥ A_min，其中 Aᵢ 是该键分区与有效域 Ω 相交后的面积，**按裁剪后的实际可点击区域计算**，不能用屏幕外面积充数。同时满足：域内每个触点有唯一归属、无遗漏、无重叠归属。平分点使用确定的稳定 ID 等规则消歧。

最小面积之和不超过 Ω 的面积只是必要条件，并不充分。重合生成元可能使多个键无法同时具有正面积；某个点包含在另一条线段中，也可能让中性权重分区不可行。后者不等于所有偏置都无解，合适偏置仍可能为点划出正面积区域；简单夹紧权重或一律要求中性分区可行，都不是通用解法。面积足够也可能只有狭长或断开的部分，因此“最小大小”最终可能还需要最小宽度、可触达内圆或连通性标准，这些尚未决定。

建议流程：

1. 先寻找并校验一份有效基线，优先尝试中性权重；求解器支持时可寻找非中性基线，不能仅因中性分区失败就断定配置无解。找不到有效基线时不激活该几何，具体编辑反馈及安全显示方式仍需确定。
2. 预测提出候选偏置，计算完整分区并验证所有参与键。
3. 不满足约束时，有限次数减弱本次调整并重新验证；不假设复杂几何的可行性随调整比例单调变化。
4. 仍失败时保留同域、同版本下的上一有效快照或有效基线；尺寸/配置已改变、旧快照不适用时，暂时回到安全可用状态。保留等级、模型和经验，不把回退当作重置。
5. 只有校验通过的分区才能发布；不得先扩张绘制，再让命中沿用另一套未经约束的评分。

[容量约束 power diagram 研究](https://brunolevy.github.io/papers/CPD_SIGASIA_2016.pdf)提供了通过权重控制区域容量的数学路线，但不能据此保证任意用户折线配置都有解，也不能直接推断手机实时性能。

### 6.4 解析几何与离散原型

建议先比较两条实现路线，再选定产品方案：

| 路线 | 优点 | 障碍 |
| --- | --- | --- |
| 解析分区与曲线边界 | 可直接表达数学边界；点生成元有较多成熟算法 | 带权混合生成元、相交与裁剪复杂；现成无权线段库不能直接补一个权重字段解决 |
| 归属栅格/距离场原型 | 便于支持点、线段、折线并验证约束；可从同一标签图提取边线和命中 | 是离散近似；分辨率影响边界、最小区域、内存和计算量，必须量化误差 |

若使用栅格，绘制和触点查询必须使用相同坐标量化及区域标签，面积约束也须说明是在这一离散表示上验证，不能宣称已经证明连续解析区域满足同样下限。若使用解析命中与近似描边，则需给出并测试绘制误差。

不得通过把线段随意采样成互不相关的多个“键”，或强行把某些像元分给已消失的键，来冒充已经满足原评分与约束。

## 7. 运行时接入建议

建议将系统分为个人词典/确认事件、页面学习、预测、几何求解、绘制与事件路由几个独立部分。现有输入引擎继续负责候选，键功能执行继续复用；触摸预测不应被某个引擎的候选返回速度绑定。

几何快照应包含页面与按键身份、布局/模型版本、可用尺寸、生成元与最终偏置、区域表示和一致的命中规则。后台可计算下一份快照，主线程只接收版本仍有效且通过约束校验的结果；过期计算不能覆盖新页面或新尺寸。

一次手势取得自己的不可变快照并使用到底。单指原型可以在 DOWN 时绑定目标，保留原状态机的 MOVE/UP/CANCEL 行为；何时允许移到另一键、哪些移出条件改变，仍需与既有 Classic/Popup 定义逐项对齐，不能逐次 MOVE 重选目标并重新触发持续操作。多指重叠手势的快照时序见待定项。

Grid 使用同一份已约束的几何。设置预览与输入法服务继续共享几何/绘制入口；Preview 展示的基础或模拟上下文应标明，不能把它当作服务当前预测状态的镜像。

Popup 目前以原矩形键中心定位。保留视觉锚点与改为生成元/区域重心是不同交互，本文不擅自切换。按压反馈、焦点及辅助功能区域也需要适配，不应继续显示或命中已从 Lv.1 隐藏的键。

## 9. 主要障碍与验证重点

| 障碍 | 预期处理方向 | 仍需证明的部分 |
| --- | --- | --- |
| 入典不等于完全无误 | 记录最终确认与可撤销贡献，区分确定标签和低置信记录 | 纠错、撤销和误选能被可靠关联的范围 |
| 词条不能唯一映射到按键 | 保留实际按键与编码来源，按引擎/文本变换确定可对齐范围 | 拼音纠错、候选补全、多字符键与跨页词条 |
| 权重可能挤掉其他键 | 验证全部区域、有限回退、只发布有效快照 | 用户自由生成元下的可行性与最小尺寸度量 |
| 显示与命中可能不一致 | 使用同一已约束几何及坐标规则 | 曲线近似、缩放、屏幕边缘和 Split 空白处误差 |
| 计算延迟与抖动 | 异步计算、版本校验、手势冻结、限定调整强度 | 各键数/折线段数下的延迟、内存、耗电与视觉变化 |
| 历史数据污染 | 唯一事件、可撤销更新、按时间分离训练与评估 | 错误样本被纠正后的恢复与模型适应速度 |
| 重置后保留模型 | 页面/按键稳定身份，几何与模型分开 | 新绑定与旧模型不兼容时的处理 |
| 分享者与使用者习惯不同 | 区分分享先验与本地增量，继续学习 | 稀疏数据、旧先验衰减和稳定性；具体规则未定 |
| 宿主编辑器行为不同 | 限定可观测确认事件，未归因变化不冒充正确样本 | 无法观察的跨应用撤销或远期改写如何处理 |

输入样本和个人词典不进入诊断日志、测试报告或仓库。学习数据的保存期限、删除入口与分享内容仍需确定，不能因为模型聚合过就默认分享包不含个人信息。

## 10. 建议分期与验收

| 阶段 | 交付物 | 进入下一阶段的条件 |
| --- | --- | --- |
| 前置：个人词典 | 应用级词典、明确入典单位与确认/修正/撤销合同 | 所有页面访问一致，失败和重复事件可辨别 |
| 采集基础 | 稳定身份、页面采集开关、经验账本、来源与可撤销序列统计 | 合成数据证明归属、去重和撤销正确；Lv.0 行为未变 |
| 几何原型 | 点/线/折线命中、边界展示、最小区域检测及退化案例 | 离线比较方案，证明绘制/命中一致并明确近似误差 |
| Lv.1 静态模式 | 自动生成、用户调整/关联、切换与仅清几何的重置 | 原手势合同、旧配置、隐藏键和无效几何回退可靠 |
| 受约束预测 | 下一键模型、低置信退避、异步快照与手势冻结 | 不挤掉其他键，预测失败/超时不阻塞输入 |
| 分享与适应 | 版本化配置、身份重映射、分享先验与本地学习生命周期 | 接收后可直接使用并持续学习，重置不误删经验 |
| 实际效果验证 | 与同一用户 Lv.0/静态 Lv.1 对照的输入评估 | 再决定是否默认推荐；不能以等级或演示代替效果证据 |

分期只规定验证顺序，不要求提前实现神经模型、整句自动入典或所有语言的分词。最终发布应包含已确认的点/线/折线能力；若某阶段仅支持点，必须标为局部原型。

测试至少覆盖：

- 几何：域内归属唯一、确定性平分、裁剪、最小区域、点/线/折线及重合/相交/零长度情况；无效和极端权重不得导致全部按键不可用。
- 手势：DOWN/MOVE/UP/CANCEL、长按、Classic 队列、Popup、持续删除/光标，以及异步权重到达、切页、旋转、可用宽度变化时的旧快照处理。
- 学习：成功/失败入典、重复事件、纠正/撤销、跨页、多字符输出、候选补全、粘贴来源、进程重建、升级绕过及重置后保留数据。
- 配置：旧 JSON 保持 Lv.0；改名、编辑、导入独立副本、分享、损坏数据及模型版本不匹配。与 [#34 Split](https://github.com/PantingEYEs/IPA_Board/issues/34)、[#36 页组文件夹导入导出](https://github.com/PantingEYEs/IPA_Board/issues/36) 的身份和坐标合同衔接。
- 效果：在按时间留出的数据和实际输入中比较误触、修正次数、输入速度及按键时延；同时比较关闭预测的静态几何，避免把生成元编辑带来的改善误算为预测效果。

所有设备回归遵守 [AGENTS.md](../AGENTS.md) 和 [测试流程](testing.md)，测试前备份、测试后恢复校验并删除备份。仅用合成或明确授权的数据。现有按 UTF-16 单元退格的产品行为保持原样，不借本功能顺带修改。

## 11. 实施前仍需阐明的边界

| 决策 | 当前边界 |
| --- | --- |
| 用户词典的入典单位与确认操作 | 先在个人词典需求中确定；自动发现词条与显式确认不混为一谈 |
| 经验累计与纠正 | 重复词条确认是否计新经验、跨页分配、无效记录撤销后是否扣经验/影响等级待定 |
| 等级与开关 | 门槛待定；允许配置升级已确定。关闭采集是否同时停用预测、是否另有预测开关待定 |
| 单键频率 | 允许收集且低置信度已确定；何时可影响区域、与上下文证据的混合和衰减待定 |
| “线”与生成元数量 | 有限线段还是允许无限直线；每个键可关联一个还是多个生成元；交叉/重叠配置的接受规则待定 |
| 几何规模与坐标边界 | 折线顶点数上限、键盘域外的生成元和缩放后的精度策略待定；非有限数据、无生成元和空域必须安全处理 |
| 最小大小 | 必须保留有效区域已确定；面积、宽度、内圆或连通性标准及数值待实测，不能提前填一个像素值作保证 |
| Split 与不连通域 | 中央空白不作为键区；左右半区的生成元是否允许跨区竞争，还是限定在各自组件内，仍需确认 |
| 权重变化与可见标签 | 标签位置保留；允许的边界变化幅度、变化节奏及标签落到其他区域时的限制待定 |
| 手势快照 | 一次手势固定已确定；多指同时输入、尺寸突变或系统取消时的规则待定 |
| 重置后的使用状态 | 仅清生成元和关联已确定；是否立即提供重新生成、保留 Lv.1 未配置状态或临时使用 Lv.0 显示待定，不得自动清模型或经验 |
| 页组间共享页面 | 数据归页面已确定；同页在不同外观/尺寸/握持模式下是否进一步细分习惯模型待定 |
| 功能与修饰操作 | 功能键、Shift/Ctrl、长按输入、候选选择是否作为预测目标、上下文或经验来源，待定；不能把不同动作都简化为一个字符 |
| 分享与导入副本 | Lv.1 可以直接分享使用已确定；是否包含模型先验、经验数、原始记录，如何分配页面身份与适应旧先验待定 |
| 页面/按键编辑和删除 | 何种编辑保留或隔离旧模型、删除页面是否删除学习、用户主动清学习的入口待定；不能复用“重置 Lv.1”去清这些数据 |
| 敏感输入与数据生命周期 | 排除范围、保留期限、导出/清除方式待定；不自动学习密码等无法合理确认的内容 |
| Preview、Popup 与辅助功能 | Preview 的模拟上下文、Popup 锚点、非矩形区域的焦点和隐藏键语义待定 |

以上待定项应在对应阶段确定，不把本文的候选算法、示例生成元、回退建议或开源参考自动转换成额外产品要求。
