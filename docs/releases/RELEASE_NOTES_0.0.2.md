# IPA Board v0.0.2

本版完善中英日混合输入与联想，新增注音转换、独立引擎开关、键盘页组和剪贴板倒序，并修复多项界面与撤销问题。

## 主要变化

- **三语候选与联想**：英文升级为 LatinIME，支持补全、拼写纠错和短上下文下一词预测；中文新增词组续写，日文新增下一词候选。混输时保留数字、标点、Emoji 和已有中日文字。
- **注音中文**：可用注音符号输入汉字，例如 `ㄋㄧˇㄏㄠˇ → 你好`；支持带调、无调、前置轻声及简繁候选，与拼音共用中文转换开关。
- **独立引擎开关**：Engine Management 提供各引擎开关与关闭后的回退说明，可控制中日文转换、英文补全／纠错、三语联想和排序等能力。**Multilingual E5 默认关闭**，开启后离线参考光标前后文重排候选，失败时保留普通候选；全部候选引擎关闭时仍可原样上屏。
- **页组与长按**：Page Group 管理键盘页的归属和顺序，颜色、高度、字号与格线按组保存；旧配置迁入 0 号组。Long-press time 可在 **200–2000 毫秒**间调整并自动保存，适用于所有键盘页。
- **全半角与计算器**：新增 **◩ 全角／半角互换**，支持英文、数字、标点、空格和片假名，可绑定功能键或快捷键。◩ 与 **∑ 行内计算模式均默认关闭**；剪贴板粘贴保持原文。
- **剪贴板面板**：采用两列等大卡片，长文仅省略预览，Unicode 和敏感内容仍完整粘贴。状态栏 **⇅** 切换整个列表的显示顺序，开启后显示 **⇅ Rev**；刷新保留方向，重新打开恢复正常。排序不改变历史或固定状态，删除撤销按当前方向恢复。
- **界面与撤销修复**：统一管理页黑灰样式，按键通过预览点击编辑；修复 Clear Keys 撤销、快捷粘贴关闭后的旧回调和编辑动作按钮被裁切的问题。候选触摸尺寸随键盘宽度调整，剪贴板容量淘汰后取消已失效的 Undo。
- **可关闭的诊断**：Debug diagnostics 默认关闭，开启后仅输出固定加载阶段与错误码，不记录输入、候选、剪贴板、短信或私人配置；关闭日志不影响失败提示和输入回退。

## 安装与更新

**系统要求：Android 15（API 35）或更高；安装包包含 arm64-v8a / x86_64 原生引擎。**

1. 下载本 Release 附件中的 **IPA_Board_v0.0.2.apk** 并安装；如系统提示，请允许安装该来源的应用。
2. 从官方 0.0.1 更新可直接安装，无需卸载；新旧包签名已核对一致，更新保留既有用户配置。实际设备升级流程尚未验证。
3. 首次安装后，在系统设置中启用 IPA Board 并选择为当前输入法；进入 **Keyboard → Keyboard Management** 配置键位。

基础输入、词库候选和 E5 在本地运行；首次使用需后台部署内置资源。Emoji 目录更新与引擎最新版查询需要联网。E5 模型和分词资源约 123 MB，首次开启需部署和加载。

## 已知限制

- 多语言输入仍受现有词库范围限制，不支持无分隔整串跨语言自动分词、整句生成或持久化个性学习；E5 语义排序为实验性功能。当前不提供运行时引擎安装或替换。
- **16KB 内存页设备兼容性尚未验证**；Mozc 与语义分词 Extensions 原生库为 4KB 对齐。
- 短信自动复制默认关闭，Broadcast 模式需短信接收权限；AutoFill 目前仅启动 SMS Retriever，尚未实现结果接收，不应视为可用的自动复制功能。
- 剪贴板历史保存于本地；敏感标记不阻止保存，系统备份规则尚未排除这部分数据。未固定项最多保留 20 条。
- 计算器仅支持基础四则运算、小数和负数，不支持括号或科学计算；结果最多显示四位小数。
- 尚不支持增删键盘布局行列；快捷键效果取决于接收应用。Emoji 目录更新不会更新系统字体。
