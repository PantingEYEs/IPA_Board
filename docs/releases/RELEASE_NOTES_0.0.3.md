# IPA Board v0.0.3

本版加入 Popup 多功能操作、可编辑多功能栏、按键盘页绑定引擎状态、Remote Keyboard Mode 第一阶段和科学计算，并完善 Emoji 浏览、输入会话恢复与运行诊断。

## 主要变化

- **Popup 多功能操作（#20）**：每个按键可独立选择 Classic 或 Popup，两套配置切换时保留。长按后滑动选择浮窗内项目，沿用经典长按的执行与取消逻辑；提供形变、项目绑定、图层、拖移缩放、撤回/重做及保存/取消/重置 Undo。支持 Pointer Location，浮窗超出屏幕时保持原位裁剪。
- **可编辑多功能栏（#9）**：在 Shortcut Management 的共享预览中，将六个固定入口分别绑定为现有功能或文本，立即持久化；status、候选栏和入口位置保持不变，Continuous Delete 沿用按住重复删除。
- **按页绑定引擎状态（#22）**：Keyboard Management → Page Settings → Choose Engines 保存该页完整开关配置。进入绑定页时应用，未绑定页保持现状，空选择表示全部关闭；普通重绘保留手动调整，配置随页面 JSON 导入/导出保留。
- **Remote Keyboard Mode（#4 Phase 1）**：`⌁` 默认入口位于 status 与全半角键之间；开启时保存并关闭全部引擎开关，退出恢复原配置。模式期间允许手动启用引擎、暂停页绑定，退出后再应用当前页配置，切换保留预输入。当前阶段提供输入模式与状态管理，不包含内置远程连接或传输。
- **Emoji 与 Caps Lock**：Emoji 常用及全部分类组成连续列表，分类菜单跳转到对应位置，滚动同步分类与 status；修复最右列被滚动触摸区域遮挡的问题（#3）。临时 Shift 与锁定大写分别显示 `Shift •` 和加粗的 `Caps Lock •`（#11）。
- **输入恢复与诊断**：修复同一输入框重新打开键盘后候选消失的场景（#1），修复分类/页组菜单抢占编辑器焦点的问题。新增可绑定的 `◷` 只读引擎仪表盘，独立显示配置与后端状态；Engine Management 提供本地日志大小查看、导出和清空，生命周期追踪遵守默认关闭的诊断开关。
- **预置与 IPA 引擎**：新增 IPA 键盘预置，更新键盘及颜文字初始化配置，升级不重新初始化或覆盖已有用户配置；已有安装需手动导入新增的 IPA JSON。实验接入 IPA → 中英日词条候选，提供独立开关及引擎/预编译二进制词典的分别更新，失败保留旧资源；客户端不编译词库。当前 IPA 引擎仅支持 ARM64，不提供下一词预测，词典与引擎仍处于开发阶段。
- **外观与触摸调试**：页组可分别设置按键预览浮窗、指针轨迹、坐标线和准星颜色，支持 Pointer Location 及差值混合；统一页面、页组及分类菜单的交互与样式。

## 科学计算（#18）

计算模式仍默认关闭，计算结果显示为可选择候选，无效算式保留原文输入。

- `()`、`[]`、`{}` 采用相同的分组语义，支持嵌套；新增 `√`/`sqrt()`、二次及嵌套根式、最简根式、`e`、`π`、`φ`、`i` 与复数计算。
- 支持 `^`、`pow()`、后缀 `%`/`!`、`perm()`、`comb()`、必须指定底数的 `log(x,b)`，以及 `sin/cos/tan/asin/acos/atan`。
- 提供小数与精确式候选；含 φ 时保留展开后的根式与符号常数形式。最终结果为角度或 tan 斜率时，提供角度、弧度、斜率各自的小数/精确式六项；无定义换算显示 `Undefined`。
- `rand(a,b)` 支持可空、可交换的实数端点，默认 `[0,1)`；同一预输入刷新时保持抽样结果，编辑算式后重新抽取，仅输出一个实数结果。

## 安装要求与已知限制

**`minSdk` 改为 26，以便通过安装流程从而收集运行故障，但本项目最低适配 API 版本仍然是 35。** 安装成功不代表低版本系统已兼容；API 26 与 HarmonyOS 4.2.0.136 实机尚未验证。API 31 诊断包的基础输入及原生引擎检查通过，但 Engine Management 和输入法 Dashboard 的部分系统 API 调用仍会崩溃。

- 应用原生库包含 `arm64-v8a`、`x86_64`；实验 IPA 引擎仅支持 `arm64-v8a`。16 KB 内存页设备仍未完成验证。
- 共用预输入退格仍可能切断 Emoji 代理对；本版未将这一 Unicode 缺陷标为修复。此前完整设备回归中的偶发 IME 窗口等待超时也尚未确认原因。
- IPA 词典质量、所有偶发无候选场景、跨进程日志汇总与远程传输不属于本版已完成的能力。当前本地诊断文件不代表全部引擎进程的日志。
