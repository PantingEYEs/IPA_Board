# IPA Board 0.0.1

IPA Board 首个版本：一款支持自定义键位的 Android 音标键盘，将 IPA 直接输入、多语言候选、表情与常用输入工具结合在一起。

## 主要功能

- **自定义键盘**：设置 IPA、多字符文本与功能键，调整颜色、键盘高度和按键比例；支持多页布局、页面排序，以及 JSON 导入/导出。
- **长按与手势**：配置长按文本、功能键、多项循环选择、持续退格和左右滑动动作。
- **多语言混合输入**：离线提供中文简繁体、英文与日文候选，支持候选展开、原样上屏及切页保留组合输入。
- **快捷键**：支持 Shift/Ctrl 配置、方向键、Home/End，以及全选、复制、剪切和粘贴等操作。
- **Emoji 与颜文字**：Emoji 分类浏览、常用表情和手动目录更新；颜文字支持标签、搜索、批量管理、使用频率排序与 JSON 导入/导出。
- **剪贴板**：本地历史、固定条目及快捷粘贴，可设置快捷粘贴保留时间和使用次数。
- **短信验证码**：可选 Broadcast 模式，通过本地规则提取验证码并复制到剪贴板，需要短信接收权限，默认关闭。
- **行内计算**：四则运算结果显示为 ∑ 候选，点击即可输入；支持小数与负数。

## 安装与开始使用

1. 下载本 Release 附件中的 APK 并安装；如系统提示，请允许安装该来源的应用。
2. 在 Android 系统设置中启用 IPA Board，并选择为当前输入法。
3. 打开应用，进入 **Keyboard Page** 配置键位；需要多语言输入时，选择“多语言 QWERTY”键盘页。

**系统要求：Android 15（API 35）或更高，arm64-v8a / x86_64。**首次使用混合输入时会在后台部署离线词库；Emoji 目录更新需要网络。

## 已知限制

- 多语言输入目前为逐词混输，尚不支持整串跨语言自动分词或持久化个性学习。
- 16KB 内存页设备兼容性尚未验证；当前 Mozc 原生库为 4KB 对齐。
- Emoji 目录更新不会更新系统字体；系统不支持的表情可能显示为名称或缺字。
- 短信 AutoFill 模式目前仅启动 SMS Retriever，尚未实现结果接收，不应视为可用的自动复制功能。
- 剪贴板文本保存于本地；敏感标记不阻止保存，系统备份规则尚未排除剪贴板历史。请及时删除不希望保留的内容。
- 计算器仅支持基础四则运算，不支持括号或科学计算；结果最多显示四位小数。
- 尚不支持增删键盘布局行列；快捷键的实际效果取决于接收应用。

## 验证情况

用户已完成手工设备验证，并反馈实际使用未发现故障。52 项单元测试通过，debug 构建和 lint 检查通过。

在 Samsung SM-G998U1（Android 15）上的自动化设备测试中，68 项有 51 项通过、17 项失败，涉及界面定位、手势、快捷键与布局断言。部分断言与当前界面显示规则不一致，其余原因仍待排查；这些测试问题计划在 0.0.2 开发周期集中处理，本版不声明自动化设备测试全部通过。以上验证不等同于签名 release APK 的验证。
