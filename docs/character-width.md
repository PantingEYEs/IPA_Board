# 全半角互换

全半角是键盘配置的辅助功能，不把所有键统一成某种宽度。关闭时直接使用按键原文；开启后才互换有对应形式的字符，例如 `a` ↔ `ａ`、`Ａ` ↔ `A`。默认关闭，继续使用已有的 `width_swap` 功能标识和可绑定入口。

## 三态操作

| 当前状态 | 点击后的状态 | 输入行为 |
| --- | --- | --- |
| 关闭 | 单次 | 只互换下一个完整字符，接收后关闭 |
| 单次，尚未输入 | 锁定 | 后续输入持续互换，直到再次点击 |
| 锁定 | 关闭 | 后续输入恢复按键原文 |

单次显示圆点，锁定显示粗体与下划线，辅助功能状态分别为“关闭”“单次”“锁定”。锁定不因候选上屏、原样确认、分段选词、移动光标、切换编辑框、换页或临时隐藏键盘而取消；状态属于当前输入法服务，服务重新创建后默认关闭。

“下一个字符”按完整 Unicode 字符边界处理。一个按键配置为 `abc` 时，单次输出 `ａbc`；配置为 `ｶﾞa` 时输出 `ガa`。浊音组合、键帽 Emoji 和 ZWJ Emoji 不拆开。没有宽度对应形式的首个字符保持原样，但仍消费单次模式；空文字和功能操作不消费。已知输入失败时保留单次，可重试；已保留在预编辑中的输入算作已接收。

## 已有文字与选区

切换状态不重新转换已有预编辑。后续输入、光标中部插入、退格、原样确认及分段候选剩余文本，都使用已经保存的实际文字。例如先输入 `abc`，再锁定输入 `def`，待输入文本为 `abcｄｅｆ`。

有选中文字时，只有 **关闭→单次** 额外互换整个选区，并保留选区方向及转换后的范围；随后单次仍等待下一次文字输入。第二次点击仅锁定，不再次转换选区；锁定→关闭也不修改选区。预编辑外的文字不随选区操作被整体替换。编辑器明确拒绝操作时不推进状态；回滚无法确认时放弃过期的预编辑范围，必要时停止当前会话继续写入。

## 候选及其他入口

字符在进入预编辑时转换一次，显示文字与提交给引擎的文字一致。不为获得候选自动还原全角编码，也不对返回的候选再次做宽度转换。因此全角拼音等输入可能没有该引擎的转换候选，可继续原样确认。计算器替换结果、完整／分段候选按实际结果处理。

普通按键、直接输入、长按／滑动／Popup 文字、Emoji 和颜文字共用同一状态。Shift 仍先处理字母大小写；Ctrl 命令与其他功能操作不消费单次宽度。候选确认本身不消费单次；空格键实际插入空格时才按该次输入的状态处理。剪贴板粘贴保持原文，不消费或改变宽度模式。

主机和设备验证通过 `width-swap` 专项执行，测试机状态保护规则见[测试流程](testing.md)。此说明不表示所有第三方编辑器均已验证。
