# App 内蓝牙键盘（#35）

入口位于设置首页的 **Bluetooth keyboard**。页面不内置另一套键盘，输入区域使用系统当前选择的输入法；可以从页面打开系统输入法选择器，不会强制切换到 IPA Board。

## 连接

点击 Start 后按需授予附近设备权限、允许启用蓝牙。应用注册标准 Bluetooth HID 键盘；只有系统回调确认后才显示就绪或已连接。可以选择已配对的接收端，或点击发现按钮、允许手机暂时可被发现，再从接收端的蓝牙设置配对。页面不扫描附近设备、不自动配对，也不要求接收端安装应用。

Android 在本应用注册为 HID 设备期间会停用手机的 HID Host 服务，因此连接到这台手机的其他蓝牙键盘或鼠标可能暂时不可用；结束注册后恢复此角色。

手机需提供 Android `BluetoothHidDevice` 能力（接口自 API 28 提供；项目当前最低实际适配版本仍为 API 35）。系统不提供此能力、权限被拒绝、蓝牙关闭、注册或连接失败时均显示对应状态。接口存在不等于所有手机与接收端组合都已验证。

Disconnect 释放按键并结束本应用的 HID 注册，不删除系统配对记录。离开页面、切到后台或锁屏时，取消尚未发送的批次并释放按键，但不主动请求断开；应用不使用前台服务保活，也不自动重连。Android 可能因应用不在前台而注销 HID；返回后按实际回调状态显示，需要时由用户重新 Start。进程被终止后不会恢复发送任务。

## 输入与两种发送模式

- **点击发送（默认）**：先在手机编辑草稿，点击 Send 时发送当前可见文字，包括仍未选词的预编辑。按钮不会替输入法选择或确认候选。
- **确认后立即发送**：预编辑先留在手机；输入法确认后发送当前未发送片段。手机不保留接收端全文镜像，因此不能同步接收端既有文字的自动更正或选区。草稿不为空时先发送或清空，再切换模式。

文字按美国英语物理键位编码，支持 ASCII 字母、数字、常用半角标点、空格、Tab 和换行。接收端的键盘布局、输入法和应用决定最终文字及快捷键效果。例如输入拼音按键可以交给接收端中文输入法转换。不能把英文按键发送成功等同于任意文字传输成功。

IPA、中文、Emoji、全角字符等没有通用 HID 文字编码，本阶段不转写、不替换、不采用针对特定系统的 Unicode 输入技巧。一次提交中包含不支持的字符时整次拒绝，草稿保留并提示。用户主动粘贴到输入区域的文字遵守同一规则；应用不主动读取系统剪贴板。

提供一次性的 Shift、Ctrl、Alt、Command/Meta 修饰键，以及常用控制键入口。每个普通按键或组合键发送按下、释放两份报告，后台及失败路径也尝试释放全部按键。输入报告被 Android 接受仅表示发送请求被接受，不证明接收端已显示对应文字。

手机输入法提供的本地复制、粘贴、选区等编辑动作仍针对手机草稿；远端快捷键使用页面的修饰键和控制键入口，不猜测不同接收端的快捷键约定。

每批最多 256 个 UTF-16 单元，先完整校验再分步发送。发送中锁定编辑；全部发送请求接受后才清空草稿。断线、中断或失败时保留整份草稿，不自动重试；已有部分按键可能到达接收端，重试前需检查接收端。未发送任务不会在重新连接、返回前台或切换设备后自动继续。

## 与 `⌁` 引擎模式的关系

使用 IPA Board 进入本应用的蓝牙输入区域时，默认进入已有的 `⌁` Remote 模式：先保存原引擎状态，再关闭引擎。已存在的快照不会被替换；同一输入页面重新建立输入连接不会再次关闭用户手动启用的引擎，也不会撤销用户明确退出 `⌁` 的操作。

引擎模式与蓝牙连接仍独立：断线、连接失败或离开页面不覆盖快照，也不擅自恢复引擎。用户通过 `⌁` 恢复原配置；即使本应用没有蓝牙连接，该模式仍能用于第三方远程键盘应用。其他输入法的引擎设置不由 IPA Board 控制。

## 验证范围

`bluetooth-remote` 专项使用模拟传输验证应用界面、输入连接、失败路径与引擎快照；真实蓝牙配对、权限弹窗、接收端收到的文字/组合键、后台后的系统行为需要实机单独验证。自动测试不扫描或配对设备、不向其他应用输入，也不将模拟测试结果标为 iPad 或其他系统的兼容证明。自动验证过程及失败后的复验记录见[测试记录](testing.md#2026-11-11-35-app-内蓝牙键盘首版)。

2026-11-11，维护者反馈真机基本功能可用，但使用体验仍需改进，并决定先收尾 #35 的 App 内蓝牙键盘首版，继续收集体验问题后再推进。此次反馈未逐项列明接收端型号/系统、手机输入法、测试键集与组合键、权限拒绝及连接异常、后台返回或进程重建场景；不据此宣称完整支持矩阵或全部验收场景均已实测通过。

输入法服务中的连接快捷入口、Wi-Fi 和 #4 剩余的完整文字/剪贴板传输要求仍属后续范围。#35 首版收尾不等于完成父任务，#4 保持开放。
